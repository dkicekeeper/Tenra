### Диагноз воронки

```
Показы стора → Страница → Установка → Активация (5 тр.) → Insights (aha) → Paywall → Trial → Paid → Renew
     ?            ?            ?             ?                  ?             ?        ?       ?      ?
```

Ни одного числа в воронке мы сейчас не знаем. При этом:

1. **0 отзывов = низкий CVR страницы.** Любой трафик (органика или реклама) конвертируется хуже, чем мог бы. Лить рекламу на страницу без рейтинга = сжигать бюджет.
2. **Измерение не настроено** (vendor number, analytics instances, RevenueCat-цели).
3. Старый план 1.1 (ASO-итерация по данным, iPad, новые скриншоты) не выполнен, а именно он повышает CVR страницы.

**Стратегическая последовательность: неделя 0 измерение → недели 1-3 социальное доказательство + CVR страницы → недели 2-4 пилот ASA на KZ → недели 4-12 масштабирование и работа с paywall.** Реклама идёт третьим шагом, не первым.

## 4. Фаза 2 — Реклама: пилот Apple Search Ads (недели 2-4, параллельно с концом фазы 1)

### Почему именно ASA, а не Meta/TikTok

- Пользователь уже ищет приложение в App Store: самый горячий интент, CVR страницы решает всё (поэтому фаза 1 идёт раньше).
- **Работает без ATT/SKAN**: атрибуция через AdServices. У Tenra «Data Not Collected», добавлять ATT-прошивку и MMP ради Meta сейчас неразумно.
- RevenueCat умеет из коробки склеивать ASA-кампанию с подпиской → честный ROAS по каждой кампании.
- KZ: дешёвый CPT (низкая конкуренция аукциона), идеальный полигон.
- Meta/TikTok/Google: отложить минимум до $1k+ MRR (нужны MMP ~$100+/мес, креативный конвейер, ATT). Вернуться к вопросу в Q4.

### 4.1 Что нужно для запуска (чек-лист, ~1 вечер)

- [ ] Аккаунт на [ads.apple.com](https://ads.apple.com): выбрать **Apple Search Ads Advanced** (не Basic: Basic не даёт ключевых слов и данных). Привязать к тому же Apple ID/организации, что и ASC.
- [ ] Платёжная карта в аккаунте ASA (вводишь сам, не ассистент).
- [ ] Проверить кредит новичка: Apple периодически даёт промокредит ~$100 новым аккаунтам Advanced.
- [ ] В RevenueCat включить Apple Search Ads Attribution (API-ключ ASA: Account Settings → API в ads.apple.com).
- [ ] Согласовать бюджет: **старт $10/день (~$300/мес) только на KZ.**

### 4.2 Структура кампаний (стандарт, не изобретать)

```
Tenra (KZ storefront, ru)
├── KZ-Brand        exact: tenra, тенра                    bid высокий (~$0.5), всегда выигрывать
├── KZ-Category     exact: учёт расходов, бюджет, расходы,
│                   деньги приложение, учёт финансов,
│                   трекер подписок, финансы               bid $0.3-0.6
├── KZ-Competitor   exact: coinkeeper, дзен мани, zenmoney,
│                   monefy, money manager                  bid $0.2-0.4 (следить за CVR)
└── KZ-Discovery    Search Match ON + broad из Category    bid $0.15-0.3, копает новые запросы
```

Бюджеты: Category 40% / Discovery 25% / Brand 15% / Competitor 20%.

Через 2-3 недели тот же каркас на **US storefront (en)**: CPT там $1-3, включать только после того, как KZ покажет trial-конверсию и на странице будет ≥ 10 оценок US.

### 4.3 Правила ведения (еженедельно, суббота, 30 мин)

- [ ] Search Terms report: новые конвертящие запросы → в exact в Category; мусор → в negative.
- [ ] Пауза ключам со 100+ тапов и 0 установок.
- [ ] Impression share < 50% на важном ключе → поднять bid на 20%.
- [ ] TTR < 3% → проблема креатива/иконки; CVR (installs/taps) < 30% → проблема страницы стора.
- [ ] Записать строку метрик в таблицу (раздел 7).

### 4.4 Юнит-экономика и стоп-лоссы

Целевые ориентиры пилота (KZ):

| Метрика | Цель | Стоп-сигнал |
|---------|------|-------------|
| CPI (стоимость установки) | ≤ $0.7 | > $1.5 две недели подряд |
| Install → Trial | ≥ 5% | < 2% (чинить paywall, не бюджет) |
| Trial → Paid | ≥ 40% | < 25% (чинить onboarding/напоминания) |
| Стоимость триала | ≤ $8 | > $15 |
| ROAS 6 мес (по RC) | ≥ 100% | < 50% после 6 недель → пауза и разбор |

Математика: annual 4 990 ₸ ≈ $9.3 gross ≈ **$8 net** (комиссия 15%, Small Business Program: если не подан в программу, подать в ASC немедленно, это +15% выручки). Значит триал должен стоить ≤ $8 × Trial→Paid. При Trial→Paid 40% допустимый CPI при 5% Install→Trial: $8 × 0.4 × 0.05 = $0.16 на установку в чистый ноль за первый год… поэтому в KZ смотрим не на мгновенный ROAS, а на: (а) стоимость данных для ASO (Search Terms), (б) LTV с продлениями и lifetime, (в) дешёвую отладку воронки перед US, где чек в 3 раза выше ($29.99 annual при глобальных ценах). Пилот = обучение за $300, не машина прибыли с первого дня.

## 6. Модель MRR (к чему идём)

Консервативный сценарий на конец Q3 (окт 2026), KZ+US:

| Параметр | Значение |
|----------|----------|
| Установки/мес (органика + ASA) | 1 200 |
| Install → Trial | 4% → 48 триалов |
| Trial → Paid | 40% → 19 платящих/мес |
| Микс: 70% annual ($8 net /12), 20% monthly ($2.5 net), 10% lifetime | ARPPU ≈ $1.0-1.5 MRR-экв. |
| **MRR через 3 мес накопления** | **$250-400** |

Рычаги в порядке силы: Trial→Paid (напоминания в триале, ценность в первые 3 дня) → Install→Trial (paywall, момент показа) → CVR страницы (оценки, скриншоты) → объём установок (ASA, ASO). Бюджет ASA масштабировать только когда предыдущие три рычага не красные.
