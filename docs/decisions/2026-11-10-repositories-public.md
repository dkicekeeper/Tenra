# The repositories stay public

**The repositories stay public** (2026-11-10): Tenra, Dalada, DesignKit, tenra-assets,
lottie-files, paws-world. Private ones would cost: macOS minutes count 10x against a private
repository's quota (Tenra alone ran about 13,200 macOS minutes in the 30 days to 2026-11-10,
about $800 a month at list price); GitHub Pages from a private repository needs GitHub Pro
(the privacy policy and terms links in the app and in App Store Connect, Dalada's site and
invite links, Paws World's support pages); jsDelivr serves public repositories only (the
logos in every installed Tenra come from tenra-assets). Kept public knowingly: the figures in
[promotion-plan.md](../promotion-plan.md) (MRR, Apple Ads budgets and bids), lottie-files as it
is, and the old values left in the history (security audit,
[archive/security-audit-2026-11-10.md](../archive/security-audit-2026-11-10.md)). The rule for
secrets: [CLAUDE.md](../../CLAUDE.md), Don't.
