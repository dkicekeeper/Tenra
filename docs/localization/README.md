## Продуктовый бриф (общий для всех переводов)

**Tenra** — приватный менеджер личных финансов для iPhone/iPad (iOS 26+).

Ключевые фичи (в порядке важности для позиционирования):
1. **Бюджеты по категориям на главном экране** — лимиты, траты и остаток на месяц.
2. **Все финансы в одном месте** — счета, депозиты (с начислением процентов), подписки, кредиты (график платежей) — **без привязки банка**.
3. **Аналитика/Insights** — куда уходят деньги; баланс, расходы, чистый поток за месяц.
4. **Финансовый скор** — оценка финансового здоровья одним баллом (сбережения, бюджеты, подушка).
5. **Мультивалютность с реальным FX** — счета в разных валютах, один честный итог в базовой валюте.
6. **Голосовой ввод** — «сказал сумму и категорию — операция записана».
7. **Импорт выписок** — PDF/CSV из банка, распознавание и маппинг операций.
8. **Приватность** — данные локально + iCloud, никакого доступа к банку, без рекламы.

Монетизация: Tenra Pro (freemium). Бесплатно: ежедневный учёт + 3 счёта.
Pro: безлимит счетов, голос, импорт PDF/CSV, депозиты, кредиты.
Якорные цены (Казахстан): 1490₸/мес, 4990₸/год (14-дней триал), 11900₸ lifetime (≈ $3 / $10 / $24).

## Инженерные воркстримы (общие для каждого языка)

Порядок работ на язык — UI-строки можно делать параллельно с фичами, но релиз на витрину
только когда готово всё:

### L1. UI-строки
- Перевести `Localizable.strings` (1347 ключей) + `Localizable.stringsdict` (2 plural-ключа).
- Плюральные категории по языкам: ru/uk = one/few/many/other; de/es/fr/tr/pt/it = one/other
  (fr/pt-BR: one применяется и к 0/1.x — проверять формулировки); ja/ko = только other.
- Процесс: AI-черновик → вычитка нейтивом → `plutil -lint` + diff-проверка паритета ключей
  (скрипт из аудита 2026-07-03).
- **Тон обращения** (закреплён существующими переводами — при добавлении строк сверяйся с ним,
  а не выбирай заново): de = Sie, fr = vous, ru/uk = вы, es/it/pt-BR/tr = неформальное «ты»,
  ja/ko = вежливый нейтральный (です/ます, 해요-стиль). Бренд «Tenra Pro» не переводится.

### L2. Голосовой ввод (VoiceInputParser + Segmenter)
Прецедент: `plans/006-voice-english-date-and-type-keywords.md` (EN-ключевики). На язык нужно:
- `expenseKeywords` / `incomeKeywords` — глаголы трат/дохода («потратил/купил/заплатил», «получил/зарплата»).
- `parseDate` — слова «сегодня/вчера/позавчера» + локальные форматы дат.
- Ключевики категорий (маппинг «такси/бензин/еда» → категории) — см. `CategoryIcon.swift` и словарь парсера.
- `VoiceInputSegmenter` — союзы-разделители («и», «потом», «ещё») для мультиоперационных фраз.
- `SFSpeechRecognizer` locale — передавать локаль пользователя; contextual strings из локальных названий категорий/счетов.
- `ServiceLogo` — фонетические алиасы локальных брендов (как «ютуб» → YouTube).

### L3. Импорт выписок (StatementTextParser + CSV)
- Ключевые слова заголовков выписки (аналог «ТРАНЗАКЦИИ ПО СЧЕТУ», «СУММА», «ОПЕРАЦИЯ») для топ-банков рынка.
- Форматы дат/чисел рынка (разделители, DD.MM vs MM/DD).
- Собрать образцы PDF-выписок 3–5 топ-банков рынка (список — в языковом файле) и покрыть тестами.
- `CSVColumnMapping` — локальные значения типов («расход/доход/перевод» → expense/income/transfer).

### L4. ASC-витрина
- Метаданные из языкового файла (после keyword research с реальными объёмами — ASA Search Popularity или ASO-инструмент; черновики в файлах основаны на экспертной оценке).
- Скриншоты: те же 8 фреймов, локализованные подписи + UI на языке рынка, суммы в локальной валюте.
- Цены: рекомендации в языковом файле; отдельные price points на рынок, не автоконвертация.
- Paywall в RevenueCat dashboard — перевести тексты оффера.

### L5. Верификация
- Прогон приложения в локали (Scheme → App Language), проверка ключевых экранов.
- Голос: 10–15 тестовых фраз на языке (суммы, категории, даты, мультиоперации).
- Импорт: образцы выписок топ-банков.
- Native review чек-лист перед сабмитом.
