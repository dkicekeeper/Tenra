# Tenra — Локализация: Украинский (uk)

> Статус: **черновик, обязательна вычитка нейтивом** (см. §7 — чувствительность к русизмам).
> Создан 2026-07-03. Фаза 4, приоритет №7 (см. [README.md](README.md)).
> Витрина ASC: `uk` (сторфронт Украина). Украинская локализация также показывается
> диаспоре на других сторфронтах, если язык устройства — украинский.

---

## 1. Обзор рынка

**Почему украинский — выгодная локаль при низком ARPU:**

- **Перевод почти бесплатный.** Структура языка близка к русскому, та же кириллица,
  та же плюрализация (one/few/many/other). AI-черновик с ru-локали + нейтив-вычитка —
  самый дешёвый язык в плане после уже готового ru. Основные затраты — не перевод,
  а вычистка русизмов и адаптация tone-of-voice.
- **Аудитория заметно лояльнее к приложениям с украинской локализацией.** Наличие
  украинского интерфейса — конкурентное преимущество само по себе; часть аудитории
  **принципиально не поставит ru-only приложение**. Украинская локаль конвертирует
  лучше, чем охват «и так поймут по-русски».
- **Диаспора по всей Европе.** Миллионы пользователей в Польше, Германии, Чехии и т.д.
  с украинским языком устройства — они увидят uk-локализацию на своих сторфронтах.
  Для них особенно актуальна мультивалютность (доход в EUR/PLN, траты в двух странах).
- **Низкий ARPU** — цены агрессивно вниз от якоря (см. §6). Ставка на объём установок
  и lifetime-покупки, а не на высокий чек.
- ⚠️ **ВАЖНО — tone-of-voice:** никаких упоминаний российских сервисов и банков в
  примерах, скриншотах, ключевиках и голосовых алиасах. Суммы в примерах — UAH и EUR.
  Не переносить ru-примеры механически: «Сбербанк», «Яндекс» и т.п. — недопустимы.

**Конкурентный контекст:** глобальные трекеры (Money Manager, Spendee, 1Money) часто
без качественного украинского; сильный локальный игрок — банковские приложения
(monobank задал высокую планку UX). Позиционирование Tenra: «все финансы в одном
месте без привязки к банку» — работает, т.к. у большинства 2–3 банка (Приват + моно)
и общей картины нет.

## 5. Адаптация фич

### 5.1 Голосовой ввод (VoiceInputParser + Segmenter)

⚠️ **Особенность матчинга — гендерные формы глаголов прошедшего времени.** В украинском
(как и в русском) глагол прошедшего времени согласуется с родом говорящего:
`витратив` (м) / `витратила` (ж), плюс средний род для безличных конструкций
(`надійшло`, `списалося`). В `expenseKeywords`/`incomeKeywords` включать **обе
гендерные формы каждого глагола** + безличные формы; матчить по основе недостаточно
надёжно из-за чередований.

**`expenseKeywords` (~20, глаголы трат):**

```
витратив, витратила, купив, купила, заплатив, заплатила,
оплатив, оплатила, придбав, придбала, віддав, віддала,
замовив, замовила, поповнив, поповнила, зняв, зняла,
списали, списалося, пішло, коштувало
```

**`incomeKeywords` (глаголы/маркеры дохода):**

```
отримав, отримала, заробив, заробила, продав, продала,
зарахували, повернули, надійшло, прийшло,
зарплата, аванс, премія, стипендія, пенсія, кешбек, дохід
```

Якорь (Казахстан): ≈ $3 / $10 / $24. Для Украины — **агрессивно вниз**: низкий ARPU,

## 7. Культурные заметки

- **«ви» — с маленькой буквы** в интерфейсах и маркетинговых текстах. Заглавное «Ви» —
  только в личной переписке; в UI выглядит устаревше-канцелярски.
- **Плюрализация: one/few/many/other** — как в русском (1 операція / 2 операції /
  5 операцій / 1,5 операції). Прецедент `.stringsdict` уже есть (ru) — механика
  переиспользуется 1:1, меняются только словоформы.
- **Чувствительность к русизмам — нейтив-ревью обязателен.** Машинный перевод с
  русского даёт кальки и суржик, которые аудитория считывает мгновенно и негативно.
  Примеры решений, которые должен подтвердить нейтив: `застосунок` (не «додаток» —
  допустимо, но выбрать одно и держать консистентно), `за замовчуванням`,
  `гаманець`, `рахунок`, `переказ` (не «перевод»), `скасувати` (не «відмінити»).
- **Апостроф** в украинских словах (`здоров'я`, `сім'я`, `зв'язок`) — использовать
  типографский `'` (U+2019) в UI-строках; парсеры/нормализация должны принимать
  и `'` (U+0027) из клавиатурного ввода и распознавания речи.
- **Никаких российских сервисов/банков** в примерах, дефолтных данных, скриншотах,
  алиасах логотипов и голосовых примерах. Только украинские и глобальные бренды.
- **Суммы в примерах** — UAH (₴) как основная, EUR/USD как валюты дохода;
  мультивалютный кейс «зарплата в евро, траты в гривне» — родной для рынка.
- **Категория донатов/сборов** — культурно значима, см. §5.1.
- Tone-of-voice: нейтрально-дружелюбный, без пафоса и без официоза; юмор — осторожно.

## 8. Чек-лист запуска

Порядок — по воркстримам L1–L5 из [README.md](README.md):

- [ ] **L1. UI-строки**: `uk.lproj/Localizable.strings` (1347 ключей) +
      `Localizable.stringsdict` (one/few/many/other); AI-черновик с ru →
      нейтив-вычитка (фокус: русизмы, «ви», апострофы) → `plutil -lint` +
      diff-паритет ключей
- [ ] **L2. Голос**: expense/income-глаголы (обе гендерные формы!), даты
      (сьогодні/вчора/учора/позавчора), союзы (і/й/та/потім/ще…), ~30 ключевиков
      категорий, алиасы брендов; `SFSpeechRecognizer` = `uk-UA`; тесты
- [ ] **L3. Выписки**: образцы PDF/CSV ПриватБанк, monobank, ПУМБ, Ощадбанк, Sense;
      заголовки колонок, даты `DD.MM.YYYY`, числа `1 234,56`; тесты парсера
- [ ] **L3. CSV**: витрата/дохід/переказ → expense/income/transfer + украинские
      заголовки колонок
