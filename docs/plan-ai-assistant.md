# План: Tenra как ИИ-помощник по финансам

> Статус: черновик плана, 2026-10-13. Решения владельца на старте: гибридный «мозг» (Apple +
> Claude), в первой полной версии агент отвечает карточками, делает действия, пишет первым и
> планирует; живёт во вкладке плюс контекстные входы с экранов; маскот вырастает из голосового
> орба. Когда план реализуется, файл уходит в `archive/plans/`, а правила оседают в новом
> `domains/assistant.md`.

---

## 1. Что получится на выходе

Вкладка «Голос» превращается во вкладку **Ассистент**. В центре живёт существо из орба: дышит,
слушает голос, думает, радуется и волнуется. Под ним пресеты и поле ввода (текст или удержание
для голоса). Ответ приходит не стеной текста, а живыми карточками приложения: графики, списки
операций, прогресс бюджетов, карточка подтверждения действия.

Четыре режима одного агента:

| Режим | Пример запроса | Что видит пользователь |
|---|---|---|
| **Спросить** | «Сколько я потратил на еду в октябре?» | Метрика с суммой, столбики по неделям, топ-3 магазина, кнопка «Открыть категорию» |
| **Сделать** | «Кофе 1500 и такси 2300 с каспи» | Две карточки-черновика с полями; «Сохранить» или правка; после сохранения тост «Отменить» |
| **Написать первым** | (сам) «Бюджет на кафе почти кончился: осталось 4 200 ₸ на 9 дней» | Сообщение в ленте ассистента и уведомление; маскот встревожен; кнопки «Показать траты», «Поднять бюджет» |
| **Спланировать** | «Сколько могу тратить в день до зарплаты?» | Сумма в день, график остатка до 10-го с учётом подписок и кредита, сценарий «а если отложу 50 000» |

Контекстные входы: на счёте, категории, инсайте и в истории есть «Спросить ассистента», и агент
уже знает, о чём речь («Разбери этот счёт», «Почему здесь так много?»).

### Урок Higgsfield, который переносится

Higgsfield вырос не на пустом окне чата, а на **пресетах**: модель упакована в готовые сценарии
в один тап с визуальным результатом. Рынок у них другой (креатив и реклама, B2B), переносится
именно паттерн:

- Первый экран ассистента: 4-6 пресетов, а не «Чем могу помочь?»: «Разбор месяца», «Где утекают
  деньги», «Сколько можно тратить до зарплаты», «Проверь подписки», «План накоплений».
- Каждый пресет: детерминированный конвейер инструментов плюс рассказ модели поверх. Без модели
  (нет сети, исчерпана квота, не тот язык) пресет всё равно показывает карточки, только без
  рассказа.
- Результат всегда визуальный, его хочется показать (скриншот разбора месяца = органика).

## 2. Ограничения, которые определили архитектуру

1. **Основная аудитория говорит по-русски, а Apple Intelligence русский не поддерживает.** По
   найденным источникам список языков Apple Intelligence (16 с iOS 26.1) русского не содержит;
   Siri AI в iOS 27 стартует с английского. Плюс около половины базы на iPhone без Apple
   Intelligence (`docs/domains/import.md`, правило 2). Только Apple = агента нет у большинства
   текущих пользователей. Отсюда гибрид.
2. **iOS 27 Foundation Models открыли две вещи** (WWDC26, не проверено по SDK, см. фазу 0):
   - протокол `LanguageModel`: облачные модели (Claude, Gemini) подключаются под тот же API
     сессий, инструментов и `@Generable`; Dynamic Profiles меняют модель и инструменты внутри
     одной сессии;
   - `PrivateCloudComputeLanguageModel`: модель Apple следующего поколения на Private Cloud
     Compute **без платы за API** для участников Small Business Program с < 2 млн первых
     загрузок. Tenra подходит (комиссия 15%). Есть квота на пользователя (`quotaUsage`,
     `.quotaLimitReached`) и проверка языка (`supportedLanguages`, `supportsLocale`).
3. **Минимальная iOS 26.** Протокол `LanguageModel` только с iOS 27, поэтому свой тонкий слой
   над моделями нужен в любом случае (см. §3.2).
4. **Сервера нет, App Privacy «Data Not Collected».** Облачный мозг требует прокси (ключ API
   нельзя класть в приложение) и честного обновления метки. Правило App Review 5.1.2(i): явно
   раскрыть передачу личных данных стороннему ИИ и получить разрешение до неё.
5. **Деньги считаются по одному правилу** (CLAUDE.md, красные флаги 6-8, 11, 15): агент не
   должен изобрести свою математику. Все суммы приходят только из инструментов поверх
   существующих сервисов.

## 3. Архитектура

```
 Вкладка Ассистент / входы с экранов / Siri / уведомления
                    │
          AgentConversation (ViewModel)  ── лента сообщений, стриминг, состояние маскота
                    │
          AgentOrchestrator (Services/Agent)
           ├─ FastPath: VoiceInputParser.parseMulti → черновик без LLM («кофе 1500»)
           ├─ ModelRouter → AgentBrain: AppleOnDevice | ApplePCC | Claude(через прокси)
           ├─ FinanceToolkit (на устройстве): read / draft / plan инструменты
           └─ ReplyComposer → [AgentBlock] → AgentBlockView (DesignKit)
                    │
          TransactionStore, InsightsService, CategoryBudgetService, BalanceCoordinator,
          TransactionDraftService, RecurringStore ... (существующее, без изменений правил)
```

### 3.1 FinanceToolkit: инструменты на устройстве

`Services/Agent/Tools/`. Один протокол `AgentTool` (имя, описание, JSON-схема аргументов,
`execute(args) async -> ToolResult`) и два адаптера: в `Tool` Foundation Models и в описание
инструмента Claude. Инструменты **всегда исполняются на телефоне**: облачная модель не видит базу,
только результаты инструментов, которые сама запросила.

| Группа | Инструменты | Опора в коде |
|---|---|---|
| Чтение | `get_spending(period, category?, account?)`, `compare_periods`, `category_breakdown`, `search_transactions(filters)`, `get_balances`, `budget_status`, `list_subscriptions` (+ следующее списание), `get_insights` (+ health score), `get_forecast` | `SummaryCalculator` / `TransactionType.summaryContribution`, `TransactionQueryService`, `BalanceCoordinator`, `CategoryBudgetService.budgetProgress`, `InsightsService` (24 типа), `SpendingQueryService` |
| Черновики | `draft_transaction`, `draft_transfer`, `draft_budget`, `draft_subscription`, `draft_recategorize` | `TransactionDraftService.makeDraft` → `commit`, `CategoriesViewModel.setBudget`, `createSeries` + `linkSubcategoriesToTransaction` (красный флаг 5) |
| План | `daily_allowance(until)`, `simulate_cashflow(changes)`, `goal_progress` | Forecasting-инсайт, `RecurringStore`, `LoanInfo`; цели после CoreData v13 |

Правила инструментов:
- **Запись только через черновик.** Инструмент возвращает `draftId`; сохраняет пользователь
  кнопкой на карточке (правило подтверждения из `docs/domains/intents.md` §2.1). После
  сохранения тост «Отменить».
- Результат несёт `Decimal` + валюту + id сущностей, **никогда** не готовую строку суммы.
- Тяжёлые проходы по 19k операций вне MainActor через снапшот (красный флаг 9), лучше через
  готовые O(1)-индексы `TransactionStore`. Кэшей в агенте не заводим (красный флаг 12).
- Pro-ограничения проверяются в инструменте (лимит 3 счетов сейчас только в UI).
- Текст из выписок и заметок (имена продавцов, комментарии) в результатах инструментов помечен
  как данные: это вход для prompt-injection, а запись и так требует подтверждения.

### 3.2 Мозг: роутер моделей

Протокол `AgentBrain`: `respond(context, tools) -> AsyncThrowingStream<AgentEvent>` (токены
текста, вызовы инструментов, финальный `AgentReply`). Реализации:

| Мозг | Когда | Цена | Приватность |
|---|---|---|---|
| **FastPath** (без LLM) | Фраза разбирается парсером: «кофе 1500», «такси 2300 вчера» | 0 | На устройстве |
| **AppleOnDevice** (`SystemLanguageModel`, iOS 26+) | Язык поддержан, вопрос простой, контекст маленький | 0 | На устройстве |
| **ApplePCC** (iOS 27+) | Язык поддержан, вопрос сложнее, квота не исчерпана | 0 (квота Apple) | Private Cloud Compute |
| **Claude через прокси** | Русский, сложный анализ и планирование; только после согласия | см. §6 | Облако, без хранения на прокси |
| **Офлайн-режим** | Нет сети, нет согласия, квота кончилась | 0 | Пресеты и карточки без рассказа |

Роутер решает по языку (`supportsLocale`), доступности (`IntelligenceAvailability`), согласию на
облако, квоте и типу запроса. На iOS 27 стоит проверить, можно ли посадить Claude под протокол
`LanguageModel` и получить один путь кода; на iOS 26 Claude идёт через свой клиент.

Прокси (`server/`, Cloudflare Worker или аналог): прячет ключ Anthropic, проверяет App Attest и
Pro через RevenueCat, держит квоты в KV, **не логирует содержимое**, имеет выключатель (remote
config), чтобы остановить облако без релиза. Аккаунты Cloudflare и Anthropic и карта: действия
владельца (§3 promotion-plan).

### 3.3 Генеративный UI: каталог блоков

Модель не рисует интерфейс и не пишет цифры. Она возвращает структурированный `AgentReply`
(`@Generable` у Apple, strict-инструмент `render_reply` у Claude):

```swift
struct AgentReply {
    var blocks: [AgentBlock]
    var mood: MascotMood          // idle, happy, concerned, celebrating ...
    var suggestions: [String]     // быстрые ответы-чипы
}

enum AgentBlock {
    case text(String)                         // короткий рассказ, стримится
    case metric(label: String, ref: ValueRef) // ValueRef = toolResultId + путь к полю
    case chart(kind: ChartKind, ref: SeriesRef)
    case transactions(ref: QueryRef)
    case budgets(categoryIds: [String])
    case insight(insightId: String)
    case comparison(a: ValueRef, b: ValueRef)
    case subscriptions(ref: QueryRef)
    case forecast(ref: SeriesRef)
    case confirm(draftId: String)
    case open(destination: AgentDestination)  // «Открыть счёт», «Открыть категорию»
}
```

Главный принцип, тот же, что в импорте («модель выводит структуру, а не значения»): **модель
выбирает, что показать; каждое число рендерер берёт из результата инструмента по ссылке.**
Галлюцинированная сумма невозможна по построению, а суммы проходят через `FormattedAmountText`
(красный флаг 7).

Рендер: `AgentBlockView` в Tenra мапит блоки на существующее: `PeriodChartAdapters` →
`LineChart`/`BarChart`, `DonutSlice.from`, `TransactionCard`, карточки инсайтов, прогресс бюджетов,
дизайн `TransactionConfirmationSnippet` для подтверждения. Новые общие компоненты по правилу
«всё в DesignKit»: `ChatBubble`, `ChatComposer`, `SuggestionChips`, `ConfirmationCard`,
`OrbCreature`. Анимации готовы в DesignKit: `StreamingText` для текста, `.thinkingShimmer` для
ожидания, `.cascadeIn` для появления блоков, `EdgeGlow` для голоса.

### 3.4 Диалоги и память

- Треды и сообщения хранятся локально (блоки как JSON). Вариант A: CoreData v13 (`AgentThread`,
  `AgentMessage`, `AgentFact`), в одном бампе с целями и долгами из backlog. Вариант B: JSON-файлы
  в контейнере (без бампа, но вне резервных копий). Рекомендую A, через `/coredata-schema-bump`.
- **Память фактов** («зарплата 10-го», «копит на машину», «каспи основной»): модель предлагает
  факт, пользователь видит и правит список в Настройки → «Что ассистент знает обо мне».
- Контекст: профиль (валюта, счета, категории, факты) компактной сводкой; последние N реплик плюс
  сжатие старых. У модели на устройстве окно маленькое, поэтому сводку держим короткой для всех
  мозгов.

### 3.5 Пишет первым

Источники уже есть: `InsightSignalService` (critical и warning с дедупом и лимитами),
`WeeklyDigestScheduler` (понедельник 09:00), `SubscriptionNotificationScheduler`,
`BackgroundInsightsRefresher`. Меняется доставка: сигнал становится сообщением в ленте
ассистента с карточками, уведомление ведёт в тред. Текст уведомления из детерминированных
локализованных шаблонов (фоновые вызовы LLM не нужны); рассказ модели генерируется, когда
пользователь открыл сообщение. Настроение маскота детерминированно следует `InsightSeverity`.

### 3.6 Маскот: существо из орба

Компонент `OrbCreature(mood:level:)` в DesignKit на SwiftUI: `MeshGradient`, `Canvas`,
`TimelineView`, Liquid Glass. Характер даёт минимальное «лицо»: две капсулы-глаза, которые
моргают, щурятся и смотрят на новый блок.

| Состояние | Поведение | Триггер |
|---|---|---|
| idle | медленное дыхание, моргание | по умолчанию |
| listening | пульс по уровню микрофона (как `EdgeGlow(level:)`) | удержание голоса |
| thinking | вращение градиента, глаза вверх | вызовы инструментов |
| speaking | лёгкий пульс в такт стриму текста | стрим ответа |
| happy / celebrating | подпрыгивание, тёплые цвета, частицы | бюджет соблюдён, цель достигнута |
| concerned | сжатие, янтарный оттенок | warning/critical сигнал |
| sleeping | приглушён, глаза закрыты | ночь, нет новых данных |

Плюс хаптика на смену настроения, уважение Reduce Motion (как в плане 009). Имя и голос
персонажа: решение владельца в фазе 0. Тон: дружелюбно, коротко, без морали и стыда за траты,
без длинных тире, на всех 11 языках.

## 4. Безопасность и качество

- Никакой записи без подтверждения; отмена после сохранения.
- Не инвестиционный советник: не рекомендует конкретные бумаги и кредиты; дисклеймер на вопросах
  про инвестиции.
- **Согласие на облако**: отдельный экран при первом облачном запросе (что уходит, куда, что не
  хранится), переключатель в настройках, бейдж «облако» на ответах облачного мозга.
- **Минимизация**: в облако уходят результаты инструментов, а не база; опция маскировать имена
  продавцов.
- **Эвал до выбора модели**: ~150 вопросов RU/EN на синтетических данных (никаких реальных
  выписок, правило CLAUDE.md). Проверяется автоматически: верный инструмент, верные ссылки на
  значения (ответ сверяется с детерминированным), уместные блоки, тон. В iOS 27 есть
  Evaluations framework для пути Apple.
- Тесты: инструменты как чистые функции над фикстурами, декодирование блоков, роутер.

## 6. Экономика облака

Цены Anthropic за 1M токенов (на 2026-10): Haiku 5.5 $0.10 / $0.50, Sonnet 5.5 $2 / $10 (чтение
кэша $0.20), Opus 5.5 $4 / $20. Допущение на одно сообщение пользователя: 2 вызова модели,
~16k входных токенов (половина кэшируется: системный промпт и инструменты), ~1k выходных.

| Модель | ≈ за сообщение | 60 сообщений в месяц | Сравнение |
|---|---|---|---|
| Haiku 5.5 | ~$0.002 | ~$0.12 | annual Pro ≈ $8 в год чистыми (≈ $0.67 в месяц) |
| Sonnet 5.5 | ~$0.03 | ~$1.70 | дороже подписки, только как «глубокий анализ» с лимитом |
| Opus 5.5 | ~$0.05 | ~$3.20 | не для потребительского чата |
| Apple PCC | 0 | 0 | квота Apple, только поддержанные языки |

Выбор модели делает владелец по итогам эвала фазы 0. Рычаги: роутер (FastPath и Apple первыми),
кэш промпта, короткая сводка контекста, лимит длины ответа.

**Риск Founding Users и lifetime:** Pro навсегда не должен означать безлимитное облако навсегда.
Облачная квота одинакова для всех Pro (честный fair-use), это нужно объяснить в момент запуска.

### Предложение по монетизации (решение владельца)

- **Бесплатно:** ассистент на Apple там, где язык поддержан; все пресеты в виде карточек;
  ~15 облачных сообщений в месяц как «ага-момент» (по аналогии с бесплатной аналитикой).
- **Pro:** облачная квота (порядка 300 сообщений в месяц плюс 30 «глубоких разборов»),
  действия, «пишет первым», планирование.
- Позже возможен отдельный уровень с большим лимитом, если данные покажут спрос.
