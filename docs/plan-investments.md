# План: инвестиции (акции, ETF, крипта)

> Статус: черновик, ждёт решений владельца (§10), 2026-10-16. Связан с
> [plan-assets.md](plan-assets.md): портфель входит в чистый капитал отдельной строкой, учёт
> устроен так же (отдельная сущность, прошлые операции не переписываются). Когда план
> реализуется, файл уходит в `archive/plans/`, правила оседают в `domains/investments.md`.

---

## 1. Что хотим

- Портфели в одном месте: брокер (Halyk Invest: акции на KASE и AIX, например Halyk Bank
  `HSBK`, Kcell `KCEL`, Казатомпром `KZAP`, и бумаги США, если брокер их даёт), биржи (Binance,
  OKX), кошельки (Telegram Wallet).
- Общая стоимость портфеля и по каждому счёту и бумаге, цены обновляются сами, прибыль и убыток,
  структура (акции KZ, акции и ETF США, крипта, деньги), доля каждой бумаги.
- Тэн разбирает портфель: что в нём, что изменилось, где концентрация, сколько принесли
  дивиденды.

## 2. Ограничения, от которых зависит весь план

1. **Цены KASE платные.** Официальный API KASE только по подписке (заявка на mds@kase.kz). С
   1 августа 2024 на сайте остались только таблицы «Рыночная оценка», выгрузки XLS/TXT/XML
   отменены. Данные KASE с лицензией на показ продаёт и Венская биржа (Wiener Börse, «Display
   Use»). Парсить сайт KASE без договора нельзя. Без договора цены бумаг KASE вводятся руками,
   как оценка квартиры; для долгосрочного портфеля это раз в неделю или месяц.
2. **Цены крипты бесплатные.** Публичные цены Binance и OKX отдаются без ключа. Запасной
   источник уже стоит в приложении: дневной курс `@fawazahmed0/currency-api`
   (`JsDelivrCurrencyProvider`) содержит `btc`, `eth`, `usdt`, `sol`, `bnb`, `okb`, `xrp`,
   `doge`, `ada`, `trx`, но не `ton`. CoinGecko Demo бесплатен, но требует указания источника и
   не даёт ясной коммерческой лицензии: не берём.
3. **Акции и ETF США (и GDR на LSE)** нужен поставщик с правом показа в коммерческом
   приложении. Бесплатные тарифы обычно только для личного использования. Ключ поставщика живёт
   на сервере Тэна, цены кэшируются там для всех.
4. **Тэн не может советовать сделки.** Правила использования Anthropic (новая редакция действует
   с 12 ноября 2026) относят к областям высокого риска «персональную рекомендацию купить,
   продать, держать или распределить между конкретными инвестиционными продуктами», а также
   советы человеку по его собственным налогам. Такая рекомендация допустима, только если её до
   показа проверил квалифицированный специалист, и человеку сказано, что её сделал ИИ. Не
   подпадают: общая информация и обучение, а также расчёт по фиксированному правилу или
   формуле, где модель не выносит суждения о человеке. В Казахстане индивидуальные
   инвестиционные рекомендации тоже дают лицензированные участники рынка после определения
   риск-профиля (проверить с юристом). Поэтому **Тэн здесь аналитик своего портфеля, а не
   советчик по сделкам** (§9).
5. **Ключи бирж только на чтение**, хранятся в Keychain на устройстве и никогда не уходят ни на
   сервер Tenra, ни Тэну.
6. **У Telegram Wallet нет API** для баланса кастодиального кошелька (есть только неофициальные
   обходы через вход в аккаунт, их не используем): он ведётся вручную. У TON Space
   (некастодиальная часть) есть адрес, его баланс читается из блокчейна публично (TON Center).

## 3. Учёт: так же, как активы

- **Портфель не счёт Tenra.** Причина та же, что в [plan-assets.md](plan-assets.md) §2: счёт
  попадёт во все выборы счёта, в карусель, в лимит «4-й счёт», в импорт и Siri, а его баланс
  менялся бы каждый день без операций, мимо `BalanceCalculationEngine` (правило #8).
- **Прошлые переводы на брокера и биржу не переписываем.** Они уже записаны в Tenra (расходом
  или переводом). Связь по категории, как аренда у активов: расход «Инвестиции» = вложено,
  доход «Вывод с брокера» = выведено. Из этого главная цифра: **вложил X, сейчас стоит Y**.
- **Дивиденды**: доход в банке с категорией «Дивиденды», подкатегория = бумага (например
  «Halyk Bank»). Получается дивидендная доходность каждой бумаги.
- **Деньги у брокера** (тенге и доллары на счёте Halyk Invest) часть портфеля. **Стейблкоины**
  (USDT, USDC) позиция с ценой около 1 USD, а не «деньги».
- **Капитал:** строка «Инвестиции» в `NetWorthCalculator` из plan-assets §5.
- Исключить переводы на брокера из «трат» в аналитике можно позже, тем же механизмом, что
  покупки активов (plan-assets §9, фаза 5).

## 4. Модель

```swift
nonisolated enum PortfolioKind: String, Codable, Sendable { case broker, exchange, wallet }

nonisolated enum PortfolioConnection: Codable, Equatable, Hashable, Sendable {
    case manual
    case binance(keyRef: String)       // ссылка на запись Keychain, не сам ключ
    case okx(keyRef: String)
    case tonAddress(String)            // TON Space и другие адреса в блокчейне (позже BTC/ETH)
}

nonisolated enum InstrumentKind: String, Codable, Sendable {
    case stock, etf, bond, fund, crypto, stablecoin, other
}

nonisolated struct Instrument: Codable, Equatable, Hashable, Sendable {
    var symbol: String                 // HSBK, VOO, BTC
    var name: String                   // Halyk Bank
    var kind: InstrumentKind
    var market: String                 // KASE, AIX, NASDAQ, NYSE, LSE, CRYPTO
    var quoteCurrency: String          // KZT для KASE, USD для США и крипты
    var priceKey: String?              // "binance:BTCUSDT", "quotes:KASE:HSBK"; nil = цена вручную
    var isin: String?
}

nonisolated struct Holding: Codable, Equatable, Hashable, Identifiable, Sendable {
    var id: String
    var instrument: Instrument
    var quantity: Double
    var averageCost: Double?           // за штуку, в quoteCurrency; nil = неизвестна
    var firstBoughtAt: Date?           // для курсового эффекта (курс на дату покупки)
    var manualPrice: ManualPrice?      // цена и дата, если источника нет
}

nonisolated struct Portfolio: Equatable, Hashable, Identifiable {
    var id: String
    var name: String                   // Halyk Invest, Binance, OKX, Telegram Wallet
    var kind: PortfolioKind
    var iconSource: IconSource?        // .brandService("binance.com"), как у счетов
    var connection: PortfolioConnection
    var holdings: [Holding]
    var cash: [String: Double]         // валюта → сумма (деньги у брокера)
    var investedLink: AssetCategoryLink?  // из plan-assets: расход «Инвестиции»
    var withdrawnLink: AssetCategoryLink?
    var lastSyncedAt: Date?
    var includeInNetWorth: Bool
    var order: Int
    var createdAt: Date
}
```

- Хранение: `PortfolioEntity` (позиции и деньги JSON-ом на строке, как взносы у целей) и
  `PortfolioSnapshotEntity` (день, стоимость в базовой валюте, разбивка JSON-ом) для графика.
  Схема через скилл `/coredata-schema-bump`; если делается сразу после активов, одним
  переходом с `AssetEntity`.
- `PortfolioRepository` (`Services/Investments/`) вне фасада, `PortfolioStore`
  (`ViewModels/`) единственный источник правды, как `GoalStore`.
- Цены не в CoreData: `QuoteStore` (кэш + UserDefaults, как `CurrencyRateStore`) с
  наблюдаемым `quotesVersion` для ключей обновления.
- История сделок (`InvestmentTrade`: покупка, продажа, комиссия) в MVP не нужна: средней цены
  хватает для прибыли. Журнал сделок в фазе 6.

## 5. Цены

| Класс | Источник | Частота | Стоимость |
|---|---|---|---|
| Крипта | публичный ticker Binance (одним запросом на все пары), запасной OKX, дальше дневной `fawazahmed0` | при открытии и pull-to-refresh, не чаще раза в 5 минут | бесплатно, прямо с телефона |
| Акции KASE и AIX | сервер Tenra `/v1/quotes` из лицензированного фида KASE | раз в день после закрытия | договор с KASE или Wiener Börse (§10.2) |
| Акции и ETF США, GDR на LSE | сервер Tenra `/v1/quotes` от поставщика с правом показа | 15 минут или закрытие дня | платный тариф поставщика (§10.2) |
| Всё остальное, и пока фида нет | цена вручную, как оценка актива | когда человек обновит | бесплатно |

- **Сервис как у валют:** `QuoteService` (фасад, как `CurrencyConverter`), `QuoteStore`
  (кэш), `QuoteProviderChain` (провайдеры по `priceKey`). Ручная цена последняя в цепочке.
- **Дата цены всегда рядом с суммой**: «HSBK 312 ₸ · закрытие 15 окт», «цена вручную от 1 окт»,
  бейдж «устарела» для ручной цены старше месяца.
- **Сервер:** новый маршрут в `server/assistant` за App Attest, кэш в KV (как квота), тикеры в
  теле `POST`, не в URL: включённое `observability` пишет пути запросов. Тикеры не логируются и
  не связываются с пользователем, App Privacy остаётся «Data Not Collected».
- **Каталог бумаг для поиска:** крипта из списка пар Binance; бумаги KASE и AIX из
  лицензированного фида (пока нет, ввод тикера вручную); США через поиск поставщика на сервере.
  Произвольная бумага с ручной ценой доступна всегда.
- **Курсы валют** для пересчёта в базовую валюту: существующий `CurrencyConverter`
  (`convertSync` с запасным вариантом, правило #6); исторический курс на дату покупки для
  курсового эффекта уже есть (Нацбанк, `fdate`).

## 6. Подключения

| Счёт | Как | Что читаем |
|---|---|---|
| Halyk Invest | вручную: бумага, количество, средняя цена; позже импорт брокерского отчёта (фаза 6, нужен образец отчёта) | позиции и деньги |
| Binance | ключ только на чтение (API key + secret). До сохранения запрос прав ключа (`GET /sapi/v1/account/apiRestrictions`): ключ с торговлей, выводом или другими правами кроме чтения отклоняется | спот, Funding и Earn: это разные кошельки, без всех трёх сумма не сойдётся с приложением биржи |
| OKX | ключ V5 только на чтение (key + secret + passphrase), проверка `perm == read_only` в настройках аккаунта | торговый счёт, Funding, Earn |
| Telegram Wallet | кастодиальный кошелёк вручную; TON Space по адресу (TON Center, публично) | TON и токены на адресе |
| Другие кошельки | по публичному адресу (фаза 6) | баланс адреса |

Правила безопасности:
- Ключи в Keychain с `kSecAttrAccessibleWhenUnlockedThisDeviceOnly`; подпись запросов (HMAC
  SHA256) на устройстве через CryptoKit; запросы идут с телефона прямо на биржу.
- Ключи не попадают в бэкап (он копирует только хранилище CoreData): на новом телефоне
  подключение вводится заново, экран говорит об этом.
- «Удалить все данные» и удаление портфеля стирают ключ из Keychain.
- Ключ и сам факт подключения не попадают ни в логи, ни в контекст Тэна.
- Синхронизация заменяет количества у подключённого счёта, средняя цена остаётся той, что ввёл
  человек (биржевой баланс её не знает); из истории сделок её можно восстановить в фазе 6.
- Binance Kazakhstan (`binance.kz`, отдельное юрлицо в МФЦА, отдельная регистрация) может
  отличаться от `binance.com` хостом и ключами: проверить на аккаунте владельца в фазе 0.

## 7. Расчёты

Один `nonisolated enum PortfolioMath` (`Services/Investments/`), как `GoalProgress`: экраны и
Тэн берут цифры только отсюда.

| Показатель | Формула |
|---|---|
| Стоимость позиции | количество × цена (в валюте бумаги и в базовой) |
| Прибыль позиции | (цена − средняя цена) × количество; % к вложенному |
| в т.ч. курс (для долларовых бумаг) | цена: `q × (p1 − p0) × fx1`; курс: `q × p0 × (fx1 − fx0)`, где `fx0` курс на дату покупки |
| Изменение за день | по ценам закрытия и снимкам портфеля |
| Структура | доли по классам, по валюте (тенге, доллар, крипта), по счетам, по бумагам |
| Концентрация | доля самой крупной бумаги и топ-3 (факт, без оценки) |
| Вложено и выведено | Σ операций по `investedLink` и `withdrawnLink` |
| Итог | стоимость + выведено − вложено |
| Дивиденды за 12 мес | Σ дохода «Дивиденды» по подкатегории бумаги; доходность к стоимости |

Ключ пересчёта по правилу #12: версия портфелей, `quotesVersion`, `mutationVersion`
операций (вложено, дивиденды), `baseCurrency`, `currencyRatesVersion` и сегодняшняя дата.
Обновление цен и синхронизация идут вне главного потока, одним запросом на биржу.

| Позиция | график цены, количество, средняя цена, прибыль с разбивкой цена и курс, дивиденды, «Обновить цену» для ручных |

| Подключить биржу | пошаговая инструкция, как создать ключ только на чтение, вставка ключа, проверка прав, понятная ошибка, если права шире |

Логотипы: Binance, OKX, Halyk через `IconSource.brandService(domain)`
([domains/logos.md](domains/logos.md)); для бумаг логотип эмитента по домену, для крипты по
тикеру (проверить провайдеры). Новые визуальные компоненты идут в DesignKit с нейтральным API.

## 9. Тэн

**Может** (информация, объяснение, расчёт по формуле):
- рассказать, что в портфеле и что изменилось («за неделю BTC −8%, портфель −3%»);
- показать структуру и концентрацию фактом («62% портфеля в одной бумаге»);
- объяснить понятия в общем виде (что такое ETF, диверсификация, как считается дивидендная
  доходность), без применения к ситуации человека;
- посчитать по правилу, которое задал сам человек: «моя цель 60% акций, 40% крипты» → текущее
  отклонение арифметикой (правило задаёт человек, модель не судит);
- писать первым о событиях: сильное движение цены, устаревшая ручная цена, ошибка синхронизации.

**Не может** (High-risk по правилам Anthropic, лицензируемо в Казахстане):
- «купи», «продай», «держи», «добавь X%» про конкретные бумаги или монеты;
- советовать, что делать с налогами самому человеку (что декларировать, какие льготы брать).

На такие вопросы Тэн отвечает фактами о портфеле и предлагает обратиться к лицензированному
консультанту брокера. Правило записывается в промпт и закрепляется кейсами eval
(`ru-should-i-buy-kzap` с отказом от рекомендации, `ru-portfolio-structure`, `en-crypto-drop`,
`ru-dividends-halyk`). Указание, что Тэн это ИИ, уже нужно по правилам для чат-ботов: проверить,
что оно есть в интерфейсе чата.

Инструменты: `get_portfolio` (счета, позиции, стоимость, прибыль, структура, концентрация,
дата цен) и `get_instrument` (цена, изменение, позиция человека). Контекст: строка
`portfolios:` (id, имя), без сумм и без ключей. Черновики: `draft_holding` («купил 10 акций
Kcell по 2 500»), сохраняются на карточке подтверждения. Контракт в
`server/assistant/src/tools.ts`.

## 10. Решения владельца

1. **Pro или бесплатно.** Рекомендую **только Pro**, как активы: данные стоят денег, а
   аудитория с портфелем платёжеспособна.
2. **Платить ли за котировки.** KASE (договор с биржей или Wiener Börse) и поставщик для США.
   Рекомендую начать **без платных данных**: крипта автоматически, бумаги KASE и США вручную.
   Запросить у KASE условия показа в приложении параллельно и подключить фид, когда цена ясна.
3. **Подключения к биржам.** Рекомендую делать (это то, что отличает трекер от таблицы), но
   отдельной фазой после ручного портфеля и только с проверкой «ключ только на чтение».
4. **Место карточки:** рекомендую сразу после «Активов» в «Финансах».
5. **Список наблюдения** (цены бумаг, которых у вас нет): рекомендую добавить в фазе 2, он
   дешёвый, раз цены уже есть.

## 11. Фазы

Каждая фаза отдельный PR со сборкой, тестами, 11 локалями (без длинных тире в строках UI).
Зависит от plan-assets: капитал (фаза 2 активов) нужен для строки «Инвестиции».

**Фаза 0. Проверки, без кода.** Запрос условий KASE (mds@kase.kz) и выбор поставщика для США с
правом показа; юридическая проверка границы «аналитика или рекомендация» (правила Anthropic с
12.11.2026, требования АРРФР); проверка API Binance Kazakhstan на аккаунте владельца; образец
отчёта Halyk Invest (реальный отчёт не коммитится, тестовые данные выдуманные).

**Фаза 1. Ручной портфель.** Модель, схема, `PortfolioRepository`, `PortfolioStore`,
`PortfolioMath`; карточка, экраны портфеля, счёта и позиции; добавление позиции и ручная цена;
крипта с ценами Binance и OKX (публично, без ключа); прибыль и структура; гейт Pro.

**Фаза 2. Цены и история.** `QuoteService` с цепочкой провайдеров; маршрут `/v1/quotes` на
сервере (когда есть фид); ежедневные снимки портфеля и график; изменение за день; список
наблюдения.

**Фаза 3. Подключения.** Binance и OKX только на чтение (Keychain, проверка прав, спот + Funding
+ Earn); TON Space по адресу; экран подключения с инструкцией.

**Фаза 4. Деньги и капитал.** Связи «вложено», «выведено», «дивиденды»; итог и дивидендная
доходность; курсовой эффект; строка «Инвестиции» в чистом капитале.

**Фаза 5. Тэн.** §9: инструменты, черновик позиции, правило в промпте, eval, сообщения первым.

**Фаза 6. Идеи.** Импорт брокерского отчёта Halyk Invest (через пайплайн
[domains/import.md](domains/import.md)); журнал сделок и доходность с учётом времени вложений
(XIRR); средняя цена из истории сделок биржи; кошельки BTC и ETH по адресу; уведомления о
цене; виджет.

## 12. Риски

- **Утечка ключа биржи** самый серьёзный риск: только чтение, проверка прав до сохранения,
  Keychain только на этом устройстве, никаких логов.
- **Несходящаяся сумма с биржей** (забыли Earn или Funding): читать все кошельки, показывать
  разбивку.
- **Устаревшая цена выглядит как факт:** дата цены всегда рядом, бейдж «устарела».
- **Лицензия на данные:** без договора не показывать котировки KASE и США из чужих источников.
- **Ответ Тэна, похожий на рекомендацию:** правило в промпте, eval на отказ, ревью ответов на
  инвестиционные вопросы перед релизом.
- **Нагрузка:** цены одним запросом, кэш, обновление не чаще раза в 5 минут; расчёты на снимке
  вне главного потока (правило #9).
