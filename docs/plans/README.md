## Findings considered and rejected

Recorded so future audits don't re-litigate them:

- **logo.dev key in `Info.plist`** — `pk_`-prefixed publishable key, designed to
  be embedded client-side. By design, not a leak.
- **`NSUbiquitousContainerIsDocumentScopePublic = true`** — required for the
  tap-to-restore-in-Files backup feature; "public" = visible to the *user* in
  iCloud Drive, not to other people. By design.
- **Supabase JWT in git history** (historic `Info.plist` revisions up to commit
  `aa37302`) — real artifact, but anon-tier key for a backend abandoned when
  logos moved to jsDelivr. **RESOLVED 2026-06-12**: verified the project host
  (`mnkgheldjygknjghcpgy.supabase.co`) returns NXDOMAIN — project is deleted,
  the leaked key is inert. No rotation possible or needed; history rewrite
  not warranted.
- **"Views over-subscribe via `transactions.count`"** — misread by the auditor;
  the touch is the *documented required* observation pattern because
  `mutationVersion` is `@ObservationIgnored` (CLAUDE.md, "Entity detail view
  refresh trigger").
- **"Deposit/Loan edit screens missing"** — false; `DepositEditView.swift` and
  `LoanEditView.swift` exist.
- **TransactionStore god-object split** — real (highest-churn, ~80 call sites)
  but L effort / HIGH regression risk mid-release-cycle. Revisit after 1.1
  ships; a fresh TransactionStore *test suite* (see plan 004 maintenance notes)
  should precede any split.
- **`FileManager.urls(for:)[0]` force-indexing (5 sites)** — real pattern,
  ~zero practical crash risk on iOS (Documents always resolves). Not worth a plan.
- **CoreData `mergeChanges` error handling, InsightsViewModel generation race,
  voice-parser index access** — auditors confirmed all are safe as written;
  defensive-hardening only.
- **Full balance recalc on MainActor (`processRecalculateAll`)** — real and
  acknowledged in code comments; deferred, not rejected. Needs the
  Sendable-snapshot treatment (CLAUDE.md Red Flag #9). Candidate for the next
  planning round; targeted recalc (`recalculateBalances(for:)`) already covers
  the common paths.
- **Detail-view refresh-pattern duplication (Loan/Deposit), SwiftLint absence,
  Makefile absence, deprecated no-op `updateRecurringTransaction`** — all real,
  all low-leverage; batch into a hygiene pass if/when one happens.
