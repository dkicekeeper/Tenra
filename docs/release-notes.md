# Tenra 1.6: What's New (ASC, 13 storefront locales)

Version 1.6, drafted 2026-10-15. Code: `main` from `ffa4541` on (TestFlight 1.6 builds 10-20).
`prepare-version` (Actions → App Store Connect, [asc.md](asc.md)) pastes each block into App Store
Connect → Tenra → 1.6 → the locale → "What's New in This Version". No em dashes (user rule).
Promotional Text stays as in 1.5. When 1.6 ships, move this file to `archive/release-notes-1.6.md`.

New since 1.5 (submitted 2026-10-12):
- Ten, the AI assistant ([plan-ai-assistant.md](plan-ai-assistant.md)): questions in plain words answered on the app's own cards; drafts saved only on Save (transactions, budgets, subscriptions, facts, goals, debts); notices it writes first (insight signals, the weekly digest, a charge tomorrow, a debt due, a goal behind); voice and receipt or statement attachments in the chat; facts it remembers, listed in Settings › Assistant; its own tab, speech bubbles and gestures, a wardrobe with accessories it earns and holiday outfits. 30 free answers in the first 7 days, then 10 a month; Tenra Pro unlimited. Claude by Anthropic through Tenra's server, after a consent screen.
- Savings goals (free) and personal debts (Tenra Pro) in Finances: cards, lists, detail and edit screens ([domains/goals-and-debts.md](domains/goals-and-debts.md)).
- Insights: the Financial Health and savings rate details open on a hero gauge, every insight detail opens on the colour of its tone, the Finances cards show icons on a shelf.
- DesignKit 4.x: rows for backups, subcategories and quick-access currencies, History's "load more" footer.

### App Privacy (the answers for the web form)

App Store Connect → Tenra → App Privacy → Data Types → Edit. "Do you or your third-party partners
collect data from this app?" Yes. Tick the five types in the table (Purchase History included),
Save, then for each: Purpose "App Functionality" only; "Linked to the user's identity" No;
"Used for tracking" No. Then Publish.

With Ten, "Data Not Collected" no longer holds: a question and what Ten looks up for it go to
Anthropic, which keeps API requests for a limited period for safety review, and Tenra's server
keeps a per-install answer count and checks Pro by the RevenueCat app user ID. Nothing is used for
tracking or ads; no data broker; no account.

| Data type (Apple's name) | What | Purpose | Linked to the user | Tracking |
|---|---|---|---|---|
| Financial Info › Other Financial Info | totals, categories, account names, transactions Ten looks up for an answer | App Functionality | No: Anthropic gets no identifier | No |
| User Content › Other User Content | the questions typed or dictated in the chat | App Functionality | No | No |
| Identifiers › Device ID | the App Attest key that counts free answers (kept until 400 days after its last use; the monthly count 40 days) | App Functionality | No | No |
| Identifiers › User ID | RevenueCat's anonymous app user ID, to check Pro (cached 10 minutes) and count Pro answers | App Functionality | No | No |
| Purchases › Purchase History | RevenueCat records the purchases against that anonymous ID (its own App Privacy guide asks for it; the 1.0-1.5 label left it out) | App Functionality | No | No |

- The privacy policy page ([public/privacy-policy.html](public/privacy-policy.html)) names Anthropic,
  RevenueCat and the rate and logo sources since the 1.6 update; it must be live before submission.

### App Review notes (paste as is)

```
Tenra 1.6 adds Ten, an optional AI assistant, plus savings goals and personal debts.

How to try Ten: tap the creature at the right end of the tab bar, then ask a question such as "How much did I spend on cafes this month?" or "coffee 1500". Before the first question goes to the cloud, a consent screen explains that Ten answers with Claude, a model by Anthropic, and lists what leaves the device (the question and the figures Ten looks up for it). Tap "Turn on". Without consent Ten still drafts plain records like "coffee 1500" on the device.

Ten never saves anything by itself: every change it suggests appears as a card with a Save button. It does not recommend specific investment products and says that picking products needs a licensed adviser.

No account or login is needed. Free users get 30 answers in the first 7 days, then 10 a month; Tenra Pro (auto-renewable subscription, sandbox purchase works) removes the limit and unlocks personal debts. Savings goals are free.

Ten answers in regions where Anthropic's API is offered; elsewhere the chat shows that the assistant is not available.
```
