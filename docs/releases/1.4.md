# Tenra 1.4: What's New (ASC, 13 storefront locales)

Version 1.4, build 1. Code: `main` after the release-1.4 merge (2026-10-05).
Paste each block into App Store Connect → Tenra → 1.4 → the locale → "What's New in This Version".
No em dashes (user rule). Promotional Text stays as in 1.3.

New since 1.3 (build of 2026-09-24):
- Wallet automation (Shortcuts → Apple Pay → "Add an expense"): category and subcategory asked once per merchant, then remembered.
- 551 icons in 18 groups with search (11 languages).
- Deposits: choose how the bank counts days (30/360 by default).
- Statement import: closing-balance check before saving; Apple Intelligence suggests categories the other tiers missed (supported devices).
- iCloud backups hidden from the Files app.
- Fixes: onboarding account and categories appear right away (fresh installs got an empty Home and one category); Settings paywalls no longer close on open.
